# 디자인 토큰

## 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg` | `#EFEFEF` | 앱 배경, 오토그래피 카드 배경 |
| `surfaceRaised` | `#F7F7F7` | 펼쳐진 챕터 등 선택된 면 |
| `surfacePill` | `#F8F8F8` | 원고 위 떠 있는 알약 버튼 |
| `ink` | `#1A0BD0` | 주요 텍스트, 선, 꽉 찬 버튼(쓰기·말하기 전용) |
| `inkSecondary` | `#4A44A6` | 보조 텍스트, 메타 정보 |
| `inkMuted` | `#7A74C9` | 힌트, 오토의 다음 제안, 단계 표시 |
| `line` | `#C4C3D8` | 목록 구분선, 진행바 바탕 |
| `ruled` | `#C9C7DE` | 노트 줄 |
| `lavenderSoft` | `#D6D2F8` | 오토 아바타 바탕 |
| `onInk` | `#FFFFFF` | 파란 면 위 글자 |
| 비활성 | opacity `0.32` | 주행 중 막힌 컨트롤 |
| 마이크 후광 | `rgba(26,11,208,.10)` | 큰 마이크 바깥 링 |

## 글꼴 (`design/fonts/`, 모두 SIL OFL)

- **Asta Sans** (가변, 300–800): UI 전반
- **Gowun Batang** (400/700): 오토의 말, 원고, 질문, ‘Autography’ 로고

## 노트 줄 (ruled lines)

- 명조로 쓴 오토의 문장에는 줄마다 아래쪽에 2px `ruled` 선을 긋는다. 선은 텍스트 영역의 끝까지 이어진다.
- 줄 높이(line-height)는 px로 고정하고, 선은 각 줄 상자의 바닥에 둔다. Compose에서는 `drawBehind`에서 `TextLayoutResult.getLineBottom(i)`에 선을 그린다.
- 시안에서 쓴 값 (글자 크기 → 줄 높이)
  - 58 → 82~84
  - 54 → 76~78
  - 45 → 64
  - 42 → 64
  - 34 → 58
  - 29 → 44
- 파란 배경 위에서는 선 색을 `rgba(255,255,255,.32)`로 쓴다.

## 크기와 형태 (960×1280 기준 px)

- 책등 띠
  - 폭 72, 오른쪽 2px `ink` 선
  - 위: 제목 세로쓰기 22/800
  - 아래: ‘Autography’ 세로 21 명조 + 설정 버튼 52 원형
- 알약 버튼: 높이 84~104, 반지름은 높이의 절반, 아웃라인 2.5px
- 원형 아이콘 버튼: 80
- 주행 홈 마이크: 220 + 후광 40 (움직이는 효과 없음)
- 진행바: 높이 12~16, 바탕 `line`, 채움 `ink`
- 칩: 높이 약 36~44, 2px 아웃라인 또는 꽉 찬 `ink`
- 글자 크기
  - 큰 명조 인사·질문: 54~58
  - 챕터 제목: 40, 펼친 챕터: 52
  - 메타: 24, 칩: 20~22
