# 시연 영상 장면 구성안 (초안, 약 3분)

- 진행: `tools/demo/demo.sh --record` (장면마다 Enter. 데모 패널 없이 adb 이벤트로 진행해 화면에 군더더기가 없다)
- 화면: Pleos Connect 에뮬레이터 전체(2560×1440). 1~2장면은 가로 전체 창, 3장면부터는 내비와 나란히.
- 소리: 에뮬레이터 소리는 Mac으로 나오지 않으므로 **알림 멜로디·오토 목소리는 편집에서 입힌다.**
  오토가 말하는 시간은 앱이 문장 길이에 맞춰 기다리므로(초당 약 7음절), 그 구간에 목소리를 얹으면 된다.
- 운전자 답변은 실제로 마이크에 대고 말한다. 파형이 목소리를 따라 움직이고, **말을 1초 멈추면**(시연 빌드. 기본값 1.5초)
  준비된 문장이 받아 적히고, 오토가 그 이야기를 이어받는 **후속 질문**을 한다(“아, 그렇군요. 아내분이 커피를 타 주셨던 거예요? …”).
- 예시 답변 3편(‘첫 차’ 43%)에서 시작하므로, 네 번 답하면(질문 4~7) ‘첫 차’가 다 찬다.
  장면 9의 두~네 번째 답변은 편집에서 2배속으로 줄인다.
- 영상 끝에 한 줄 고지: “음성 인식·합성은 Pleos SDK 승인 전이라 시연용 시나리오로 재생했습니다.”

## 촬영 전 확인

- [ ] Android Studio에서 에뮬레이터를 켜고 디버그 빌드를 설치했다
- [ ] `demo.sh --reset`으로 예시 답변 3편(‘첫 차’ 43%)에서 시작한다
- [ ] Mac 마이크: 이어폰 마이크를 쓰고, 처음 한 번 macOS 마이크 권한을 허용했다
- [ ] 에뮬레이터 시계·배터리 표시가 영상에 거슬리지 않는다
- [ ] 장면 4·8의 5초 제안은 Enter를 바로 눌러 `yes`를 보낸다(늦으면 제안이 닫힌다)
- [ ] 장면 6·9에서 말을 멈췄는데 받아 적지 않으면 `a` + Enter로 말을 끝낸다(`answer`)
- [ ] 장면 9에서 다 채운 뒤 더 말하면 덧붙인 이야기로 저장된다. 촬영에서는 바로 `finish`로 넘어간다
