# 시연 영상 장면 구성 (약 90초, 7장면)

- 진행: `tools/demo/demo.sh --reset --record` (장면마다 Enter. 데모 패널 없이 adb 이벤트로 진행해 화면에 군더더기가 없다)
- 시작 상태: `--reset`이 앱 데이터를 지우고 시연용 서재를 만든다.
  ‘김○○의 자서전’ · 부르는 이름 ‘○○님’ · 1장 ‘나의 뿌리’ 완료 · **2장 ‘첫 차’ 5/7편(71%)**. 두 번 답하면 ‘첫 차’가 찬다.
- 화면: Pleos Connect 에뮬레이터 전체(2560×1440). ①은 가로 전체 창, ②~⑥은 내비와 나란히(세로 한쪽 창), ⑦은 다시 가로 전체 창.
- 소리: **알림 멜로디와 오토 목소리는 편집에서 입힌다.** 앱은 오토가 말하는 시간만큼(초당 약 7음절) 기다리므로 그 구간에 대사를 얹는다.
- 운전자 답변은 실제로 마이크에 대고 말한다. 파형이 목소리를 따라 움직이고, 말을 1초 멈추면(시연 빌드) 준비된 문장이 받아 적힌다.
  받아 적지 않으면 `a` + Enter로 말을 끝낸다(`answer`).
- 영상 끝 고지: “음성 인식·합성은 Pleos SDK 승인 전이라 시연용 시나리오로 재생했습니다.”

## 오토 대사 (목소리 입힐 대본)

화면에 쓰이는 문장과 같다. 괄호 안은 운전자(실제 녹음) 또는 연출.

**①** (대사 없음. 자막) 정차 중에는 챕터를 고르고 원고를 봅니다.

**②**
> 좋은 하루 되세요! ‘첫 차’ 부분을 쓰고 있어요.

(자막) 출발하면 말로만 쓰는 화면으로 바뀝니다. Pleos 내비와 나란히.

**③** ♪ 알림 멜로디(짧은 두 음) 뒤에
> 지난번 ‘첫 차’ 이야기, 이어서 해 볼까요? 조금만 더 채워 주시면 이 챕터가 완성돼요!

(운전자) 응.

**④**
> 그 차와 함께한 날 중 가장 힘들었던 날은요?

(운전자) 눈 오는 밤에 고개에서 차가 미끄러졌어요. 지나가던 화물차 기사님이 체인을 감아 주셨죠.

> 지나가던 기사님이 체인을 감아 주셨군요. 그럼 그 차와 헤어지던 날은 어땠어요?

**⑤** (운전자) 십 년을 탄 차를 폐차장에 두고 오던 날, 아들이 울었어요. 저도 사실 좀 울었고요.

> ‘첫 차’를 다 채웠어요! 더 하실 이야기는 이어서, 마무리는 “여기까지”라고 말씀해 주세요.

(운전자) 여기까지.

(자막) 챕터 완성 — 답변은 받아 적는 즉시 저장됩니다.

**⑥** (운전자) 오토야, 뭐해?

> ‘일과 생계’ 부분을 다듬고 있었어요. 여기에 대해 조금 더 이야기해 주시겠어요?

(도착 9분 전, 새 질문 대신)
> 도착이 곧이니, 이따가 이어서 작성을 도와드릴게요!

(자막) 목적지 10분 전에는 새 질문을 하지 않고 저장 후 마무리합니다.

**⑦** (대사 없음. 내레이션) 운전한 시간만큼 자서전이 쌓입니다. + SDK 고지

## 촬영 전 확인

- [ ] Android Studio에서 에뮬레이터를 켜고 최신 디버그 빌드를 설치했다
- [ ] `demo.sh --reset`으로 시작한다(시연용 서재, ‘첫 차’ 71%)
- [ ] Mac 마이크: 이어폰 마이크를 쓰고, 처음 한 번 macOS 마이크 권한을 허용했다. 주변 소음이 크면 저절로 받아 적힐 수 있다
- [ ] ③의 5초 제안은 Enter를 바로 눌러 `yes`를 보낸다(늦으면 제안이 닫힌다)
- [ ] ④·⑤에서 말을 멈췄는데 받아 적지 않으면 `a` + Enter
- [ ] ⑥은 ‘일과 생계’ 질문을 읽는 동안 Enter를 눌러 `arrival10`을 보낸다(인터뷰 중일 때만 마무리 화면이 뜬다)
- [ ] 환경설정의 ‘오토가 먼저 말 걸기’와 ‘알림 멜로디’가 켜져 있다(`--reset`이면 켜져 있다)
